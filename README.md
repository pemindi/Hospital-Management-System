# Hospital Management System (HMS)

Internship assessment project — a full-stack Hospital Management System built with the MERN stack (MongoDB, Express, React, Node.js).

## Tech Stack
- Frontend: React (Vite), Tailwind CSS, React Router, Axios
- Backend: Node.js, Express.js
- Database: MongoDB (Atlas)
- Auth: JWT, bcrypt
